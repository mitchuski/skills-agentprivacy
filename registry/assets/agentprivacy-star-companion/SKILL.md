# agentprivacy-star-companion

Reuse the keeper-approved bottom-right floating Star: click for a compact key picker, Customise Star link and minimal connection state. Leave fuller explanation to the extension and linked guide. Avoid another large homepage onboarding panel or conflicting status widget. Preserve the existing wandering-orb game and casting economy.

Use allowlisted palette projection, optional key commitment verification and tab-session storage. Never retain a full private key/bundle in the page merely to style it. Unknown imported authentication flags cannot set verified state. Handle storage failure, forgetting, reload, keyboard focus/Escape, reduced motion and stacking independently of the decorative scene.
